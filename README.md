# AssessAI

AI-powered assessment intelligence platform that uses RAG and LLMs to generate, validate, evaluate, and personalize assessments from instructor-provided learning content.

## Objective

AssessAI aims to help instructors create high-quality, curriculum-grounded assessments while providing students with personalized evaluation and practice.

## Core Features

* Instructor and student authentication
* Course and content management
* RAG-based learning content retrieval
* AI-powered assessment generation
* Structured question generation
* AI-based question quality validation
* Instructor review and publishing
* Automated assessment evaluation
* Student performance analysis
* Personalized assessment generation

## Planned Technology

* Python
* FastAPI
* Streamlit
* PostgreSQL
* Qdrant
* Gemini
* Docker
* Git/GitHub

## Architecture

The application is designed as a modular AI-powered backend that can later be integrated into an existing LMS.
